# Lines of crates/ps_sim/src/mods/genN/** that the coverage gate
# (scripts/ps-coverage.sh, V-1) accepts as never run: each is dead under
# the formats the gate plays or unreachable in Showdown too. PS line
# numbers are at the pin (tools/ps-diff/node_modules/pokemon-showdown).
#
# A line entry names a file and the source text of its lines, not line
# numbers, so it survives edits elsewhere in the file:
#
#   <path under crates/ps_sim/src>  <selector>  <reason>; PS: <file>:<line>
#
# The selector is one or more anchors, each a trimmed source line in
# backticks (the whole line, leading and trailing blanks dropped):
#
#   `text`               the line whose trimmed text is `text`;
#   `text`#2             its 2nd occurrence in the file, when it repeats;
#   `text`@120           the occurrence nearest line 120, when it repeats
#                        (a hint: it only picks among repeats);
#   `a` > `b`            the first `b` after `a` (chains: `a` > `}` > `}`
#                        is the second `}` after `a`); a repeated line, a
#                        closing brace above all, is best named this way;
#   `a` .. `b`           the range from `a` to the first `b` after it
#                        (`a` .. `x` .. `b`: to the first `b` after `x`).
#
# `#n` and `@n` go on the first anchor only. A text that repeats with no
# `#n`, `@n` or `>` chain is an error. An entry covers every unrun line in
# its range. The script reports entries whose text is no longer in the
# file, and entries none of whose lines is unrun (the line now runs), as
# stale. `scripts/coverage-allow.py --check` checks that every entry still
# resolves (scripts/check.sh runs it); `--show` prints the lines each
# entry resolves to now.
#
# `handler <gen> <kind:id> <key>  <reason>` entries exempt a registered handler
# from the 20-battle hit gate the same way (PS's data gives the effect the
# handler, so the registry must carry it, but gen 1 never calls it).
#
# A closing-brace line counts the implicit `else` of the `if` it closes
# (llvm-cov), so "never runs" there means "the condition is never false".
