# Pinned seeds for the Showdown protocol-diff harness (`ps_sim_cli`
# vs PS regressions).
#
# Format, one entry per line:
#   <gen> <teams> <seed>  # <commit> <note>
# where `<teams>` is `random` or `wide`, `<seed>` is a non-negative u32
# driver seed, `<commit>` is the integrating commit on `ps-split`, and
# `<note>` is a free-form tag for the corridor the entry covers.
#
# The harness reads this verbatim and replays every entry as a single
# self-contained battle: PS against `ps_sim_cli` when `--ps-cli` is given
# (as `scripts/check.sh` does, with `--allow-unported`), PS against itself
# otherwise. Empty / comment-only files are allowed.
#
# Add an entry when a port fails a seed the integration found: the
# seed replaces the regression's red-by-red march with a single pin
# that lands in the same gate.
