# Pinned seeds for the Showdown protocol-diff harness (`ps_sim_cli`
# vs PS regressions).
#
# Format, one entry per line:
#   <gen> <teams> <seed>  # <commit> <note>
# where `<teams>` is `random` or `wide`, `<seed>` is a non-negative u32
# driver seed, `<commit>` is the integrating commit on `ps-split`, and
# `<note>` is a free-form tag for the corridor the entry covers.
#
# The harness reads this verbatim and replays every entry as a single
# self-contained battle: PS against `ps_sim_cli` when `--ps-cli` is given
# (as `scripts/check.sh` does, with `--allow-unported`), PS against itself
# otherwise. Empty / comment-only files are allowed.
#
# Add an entry when a port fails a seed the integration found: the
# seed replaces the regression's red-by-red march with a single pin
# that lands in the same gate.

# P1-8: `gen1randombattle` was not a format ps_sim knew, so every
# `--teams random` battle crashed at `>start`. These four ran longest
# before reaching an unported status or move.
1 random 158  # P1-8 gen1randombattle rules and tier; unported stop after 19 turns
1 random 22  # P1-8 gen1randombattle; long ported prefix
1 random 1  # P1-8 gen1randombattle; long ported prefix
1 random 90  # P1-8 gen1randombattle; long ported prefix

# P1-9: `gen3randombattle` was not a format ps_sim knew (every gen 3
# `--teams random` battle crashed at `>start`), and an item or ability
# whose handlers had no port was skipped silently instead of stopping
# `unported`, so the battle diverged from PS. Since P1-9 the team and
# choice seeds are four u16 (they were two, which made PS's PRNG return
# 0 forever: every seed played the same teams and choices), so the P1-8
# entries above now play other teams than when they were pinned.
