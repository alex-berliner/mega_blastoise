# The pinned regression corpus for the legacy Gen 3 engine. (The Gen 1

# `scripts/ps-diff.sh --carried gen1`.)
#
# Every entry is a seed that found a bug, kept as a test that must stay
# green. One entry per line:
#
#   <suite> <wide 0|1|2> <seed> [case=<k>] [only=<ids>]  # <fix commit> <note>
#
#   suite  the showdown_fuzz test to run (fuzz_gen3_battles, ...)
#   wide   0, 1 or 2: the FUZZ_WIDE level the seed was found at
#   seed   the FUZZ_SEED the seed was found with
#   case   optional: compare only this case of the seed (FUZZ_CASE)
#   only   optional: narrow the move pool to these ids (FUZZ_ONLY)
#
# Everything after the `#` says where the finding came from; it is a note,
# not part of the run. Run the whole corpus with
#
#   scripts/pinned-seeds.sh
#
# The volume is the one the seeds were found at (FUZZ_N=200, the default).
# The filter's saving grows with the volume (at FUZZ_N=200 a case= entry runs
# about 2x faster than the whole seed, at FUZZ_N=2000 about 6x), because the
# reference pays a fixed start-up per run either way.
