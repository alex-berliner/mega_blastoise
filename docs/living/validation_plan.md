## 1. Agreed validation plan, in order

### A. Before ordering

**Day 1: decide the known copper changes and buy parts (1 day)**
- Put the cell, spacer, speaker, 6 mm hole and ribs into design.py, placement.py and positions.json.
- Add an external pull-down on PWR_HOLD (GPIO2), 8.2k or less (Fable picks 4.7k).
  - Why: erratum RP2350-E9 can hold a released pad near 2 V. Through D2 that keeps the ME6211 enabled, so the unit stays on after a crash and drains the cell in a bag.
  - Also rewrite docs/pinmap.md:75 ("GPIOs float, pulled low").
- Drive TP4056 CE from a GPIO, with 100k to VBUS so a dead MCU still charges. Any gate in that path gets an external pull-down (E9).
- Add JP1, a 0R in the 3V3 feed, plus 1 mm test pads on PWR_EN, LS_GATE and AMP_SHDN.
- Add the rev silk and a 2-bit revision strap. Every strap or gate that relies on a pull-down gets an external one.
- Add DNP RF caps on CHG_TEMP, CC1/CC2 and LCD_RST.
- Put the JLCJLCJLCJLC text under the spacer, away from the combs.
- Buy now:

**Phase A1: check the parts against primary sources (about 1 week, runs before the freeze)**

- **Pin tables (#1/#113, #109).** One table per IC: datasheet pin, function, design.py net, electrical class (tie-high, tie-low, may-float, bonded), and a page quote. This catches a wrong pin number or a floating CMOS input on VSYS or VBUS that ERC and parity cannot see.
- **FM8002A (#114).** Check the shutdown polarity in C94625's own datasheet.
- **Errata (#41/#138).** One table: each erratum, whether it applies here, and the fix.
- **Inherited claims (#196).** The four comment claims every reviewer accepted get a primary-source citation, or are marked open.
- **Application circuits (#38/#170).** Diff each IC against its datasheet application circuit.
- **GPIO mux (#55/#140).** Script design.py's GPIO list against the RP2350 function table. This catches a GPIO that cannot do its assigned job.
- **LCSC identity (#2/#122).** Script each C-number to its MPN, package, pin count and voltage. This catches the wrong variant of the right part.
- **Footprints (#115, #3).** Overlay the easyeda2kicad footprints on ours for pad geometry. Check pin numbering by hand for D2, Q1, Q2, U3, D3 and D6.
- **Charge current (#128).** Set R5 from the 403450's spec sheet. The current 460-500 mA is probably too high for this cell.
- **Capacitor derating (#6/#124).** Apply DC-bias derating to C9, C1 and the 0603/0402 caps and re-run the unplug and hot-plug ODEs. If C9 collapses, it becomes two parts, which is a copper change.
- **Failure table (#89).** A short FMEA of D5, D7, Q2 and U2. A shorted D7 or Q2 charges the cell straight from USB with no regulation.

### C. Bring-up (2-3 weeks after the boards arrive)
1. **Chip identity first.** Read the chip ID and stepping, and check the flash JEDEC ID with picotool (#179/#217). Then repeat the PWR_HOLD release measurement on the real board before the cell is ever left connected unattended.
2. **bringup.md as written (#147).** First fix the two wrong step-0 expectations: R38 is exactly 1k, and D7 reads about 0.25 V, not 0.6 (#91).
3. **Probing.** Coax pigtails on the test points for the hot-plug and unplug scope captures (#52/#152). Then test weak sources (#80), legacy USB-A hosts (#94) and a range of chargers (#51).
4. **Currents.** Off-state current with a PPK2 (#33/#148). Cell emulation sweep from 3.0 to 4.2 V (#61/#149).
5. **Temperature.** Thermocouples during a full charge in the closed case: cell, U2, case skin (#31/#47/#93). TH1 window with a hair dryer and a cold pack (#30/#150).
6. **Audio and backlight.** Audio carrier, pops and heat (#65/#153). Backlight current per cathode pin and the sinks' step response (#60/#191).
7. **Faults and margins.** Abuse tests on a sacrificial board (#151). Margin-to-failure tests (#85).
8. **Emissions and ESD.** Near-field EMC scan (#67/#162). ESD screen (#163).

### D. Firmware (starts now, does not gate the order)
- **Pins and memory.** Generate pins.rs from design.py and compile it against embassy-rp rp235xb (#56). Add memory-rp2354b.x with 2048K of flash (#180).
- **Bring-up firmware.** The bring-up UF2 runs on a B-package dev board (#57/#141). The watchdog is enabled before any blocking init.
- **Panel driver.** Develop the ILI9488 driver on a module first, then move it to the real panel (#58). Start from EastRising's init values (#211).
- **Power and charging.** The power-off sequence is DISPOFF, then SLPIN, then drop the hold (#181). TP4056 status decoding has to handle the blinking states (#100).
- **Flash safety.** Flash journal and power-cut rules (#83). Hashed single-slot update image (#214). No OTP or seal commands in any script (#202).

## 3. Considered and deliberately skipped
- **Second PROG resistor on a GPIO:** it adds a failure mode to the cell's current path; CE on a GPIO gives firmware enough control.
- **Second-tool copper rebuild from the gerbers (gerbonara):** IPC-D-356 plus JLC's netlist e-test covers it.
- **PSRAM footprint near the copied core:** deferred entirely.
- **Hobby TP4056 module as the latch gate:** its DW01/FS8205 and different PROG parts test a different circuit.
- **Load-share bench test as an order gate:** the ODEs and bring-up #52 cover it.
- **10k pull-down on PWR_HOLD:** above E9's 8.2k guidance.
- **A rigid spacer:** swelling needs a compliant layer, so PET film plus foam.
- **Not order-gating, deferred until after ordering:** case FEA (#111), CTE drift (#106), dome venting (#112), latency rig (#107), reliability ranking (#110).
- **Deferred until a sale:** IP audit (#108), regulatory marks (#204), material compliance (#218), EMC/ESD test house.

214. **Field firmware-update flow: hashed single-slot image, flash layout fenced by a partition table, pull-the-cable update test** (Opus, firmware-hardware, before ordering (layout decision), at bring-up (pull test)): A torn UF2 write leaving a half-image that boots and crashes. Note: an update over USB always has VBUS holding PWR_EN through D3, so the cell-only case arises only from that command. #171 covers paperclip recovery and #191 covers OTP rules; nothing covers the normal user update. *How:* Decide before ordering, because it fixes the flash budget in #169: single slot plus ROM BOOTSEL (mask ROM, cannot be bricked) as the recovery path.
