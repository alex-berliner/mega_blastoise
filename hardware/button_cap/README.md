# Button caps for the Adafruit 12x12 mm tactile switches (TC-1212T style)

Printable caps that snap onto the round plunger of the 12x12x7.3 mm tactile
push buttons used on the board (SW1..SW14).

| File | Shape | Size | Source |
|------|-------|------|--------|
| `tactile_switch_cap.stl` | square, like the stock Adafruit cap | 13 x 13 x 8.3 mm | [Printables 236991](https://www.printables.com/model/236991-tactile-switch-push-button-cap) by Jona32u4 |
| `button_cap_12x12.stl` | round remix of the above | 11.3 mm dia x 8.3 mm | [Printables 367373](https://www.printables.com/model/367373-tactile-switch-push-button-cap-12x12) by HeiLaut |
| `button_cap_12x12.scad` | OpenSCAD source of the round remix; imports `tactile_switch_cap.stl` | | same as above |

Both models are licensed Creative Commons Public Domain.

Print notes: designed to print upside down (top face on the bed), no supports.
If the fit on the plunger is loose or tight, adjust with horizontal expansion
in the slicer, or rework in OpenSCAD via the .scad file.
