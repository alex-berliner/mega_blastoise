# Hardware

[`ref_design/`](ref_design/README.md) is the hardware source: the board (generated from `board/design.py` and
`board/placement.py`), the case (`case/case.scad`), their build pipeline, fab outputs, print kits and the 3D viewer. Its
README says how to rebuild it; build output (gerbers, STLs, STEP, renders) is not committed where a script makes it.

What the product is: [docs/static/DESIGN.md](../docs/static/DESIGN.md). The next spin's requirements and chosen parts:
[docs/static/next_spin_requirements.md](../docs/static/next_spin_requirements.md). Terms: [docs/reference/hardware_glossary.md](../docs/reference/hardware_glossary.md).
DS Lite research: [docs/reference/ds_lite/](../docs/reference/ds_lite/README.md). Earlier generations: [docs/archive/hardware_history.md](../docs/archive/hardware_history.md).
