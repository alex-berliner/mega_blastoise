# Coverage grid: check classes by subsystem (REF-A, hardware/ref_design)

Generated by `python3 hardware/vv/tools/grid.py` from verification.csv (each check's `classes` and `subsystems`) and grid_reasons.csv. Do not edit by hand: change those files and re-run it. `check_trace.py --gate order` fails (R9) while any cell of classes 1-15 is GAP or planned. A cell of classes 1-14 is cleared only by a check that runs before the boards exist and has run (PASS or FAIL): an ORDER check or an analysis (A), printed with its phase when that is not ORDER (VER-05@EVT); a NOT_RUN one leaves the cell planned; a later bench test, inspection or demonstration measures it but does not clear it. Class 15 is cleared only by a paper estimate that has run: an analysis with a PASS or FAIL. Classes 16-18 belong to EVT, DVT and PVT and are shown, not gated by the order; 19 and 20 are whole-register classes, listed below. Only checks of board ref_design or both count; CUT and RETIRED checks never do.

A cell reads: COVERED, worst <status> (FAIL, BLOCKED, NOT_BUILT, NOT_RUN, ACCEPTED, PASS) among the checks that can clear it (classes 16-18: among all its checks) and, when no clearing check is an ORDER check, the earliest phase, then the later checks that measure it but cannot clear it; planned (the checks that could clear it once built and run, then the ones that measure it but cannot clear it: a GAP for the order gate); GAP; NOT_NEEDED (grid_reasons.csv says why); ACCEPTED_GAP (signed: a grid_reasons.csv ACCEPTED_GAP row and Alex's signed GRID-<class>-<subsystem> line, both). BLOCKED is a PASS that rests on a datasheet not in hardware/ref_design/datasheets: it clears nothing and no gate counts it. ACCEPTED is a check that a defect Alex moved to a later gate with a signed DF-ACCEPT line names: the order gate lets it through, and it is not a PASS.

What 'classes 1-15 pass before the order' means: R9 holds a cell until a check that can clear it has run, and G-ORD-22 holds every ORDER check until it passes or is ACCEPTED with a signed line. A FAIL in a cell from a check of a later phase (VER-103@EVT, say) does not hold the order: its defect's Gate does.
